# ១. វិសាលភាពគម្រោង

## បញ្ហា

ម្ចាស់ផ្ទះជួលតូចៗកត់លេខកុងទ័រ វិក្កយបត្រ និងប្រាក់ក្នុងសៀវភៅ។ ការគណនាដោយដៃងាយខុស ប្រាក់ ABA ងាយច្រឡំ ហើយអ្នកជួលមិនអាចមើលវិក្កយបត្ររបស់ខ្លួនបាន។

## គោលបំណង

1. កត់ត្រាទឹកភ្លើង វិក្កយបត្រ និងប្រាក់ចូលឲ្យត្រឹមត្រូវ (សាច់ប្រាក់ + KHQR)។
2. ចេញវិក្កយបត្រថ្ងៃ ៣០ ដោយគណនាស្វ័យប្រវត្តិ (ទឹកភ្លើងខែនេះ + ថ្លៃផ្ទះខែក្រោយ)។
3. អ្នកជួលមើលវិក្កយបត្រ បង់ KHQR ស្នើជួសជុល និងអានកិច្ចសន្យាតាម Web portal។
4. ម្ចាស់ផ្ទះឃើញចំណូល ចំណាយ ចំណេញ/ខាត និងផ្ទៀងកុងទ័រធំជាមួយ EDC / PPWSA។
5. រក្សាទិន្នន័យអ្នកជួលឲ្យមានសុវត្ថិភាព។

## ការសន្មត

- អគារតែមួយ ម្ចាស់ផ្ទះម្នាក់ អ្នកជួលម្នាក់ក្នុងបន្ទប់មួយ។
- អានកុងទ័រថ្ងៃ ២៨ ចេញវិក្កយបត្រថ្ងៃ ៣០ ថ្លៃផ្ទះបង់មុន។
- បុគ្គលិកបញ្ជាក់ប្រាក់ ABA ដោយមើលគណនីពិត មិនមែនរូបតែប៉ុណ្ណោះ។
