## គ.1 តួនាទីនីមួយៗធ្វើអ្វីបាន

បុគ្គលិកធ្វើការងារប្រចាំថ្ងៃ អ្នកមើលមើលបានតែមើល ហើយការសម្រេចចិត្តលើប្រាក់នៅជាមួយម្ចាស់ផ្ទះ។ គណនីនីមួយៗប្រើដោយមនុស្សម្នាក់ កុំឱ្យគ្នាខ្ចីពាក្យសម្ងាត់។

| ការងារ | បុគ្គលិក | អ្នកមើល |
| --- | --- | --- |
| មើលបន្ទប់ អ្នកជួល វិក្កយបត្រ | ✔ | ✔ |
| អានកុងទ័រ និងចាក់សោខែ | ✔ | ✘ |
| បន្ថែម/កែអ្នកជួល ប្រាក់ចូលស្នាក់ ចាកចេញ | ✔ | ✘ |
| ចេញវិក្កយបត្រ ទទួលប្រាក់ បញ្ជាក់បង្កាន់ដៃ ABA | ✔ | ✘ |
| សំណើជួសជុល និងសេចក្តីជូនដំណឹង | ✔ | ✘ |
| បោះពុម្ពវិក្កយបត្រ និងកិច្ចសន្យា | ✔ | ✔ |

## គ.2 ការងារបុគ្គលិក

បុគ្គលិកធ្វើតាមជំពូកដូចគ្នានៅផ្នែក ខ។ ខាងក្រោមជាច្បាប់បន្ថែម។

| ការងារ | មើល | ច្បាប់បុគ្គលិក |
| --- | --- | --- |
| អានកុងទ័រថ្ងៃ ២៨ | ខ.5 | ថតរូបគ្រប់កុងទ័រ។ មានការព្រមាន → ប្រាប់ម្ចាស់ផ្ទះមុនចាក់សោខែ។ ចាក់សោរួច មានតែម្ចាស់ផ្ទះបើកវិញបាន។ |
| ចេញវិក្កយបត្រ | ខ.7 | វិក្កយបត្រខុស → កុំចេញថ្មី សូមប្រាប់ម្ចាស់ផ្ទះឱ្យទុកចោល។ |
| ទទួលសាច់ប្រាក់ | ខ.8 | កត់ភ្លាមនៅថ្ងៃដដែល និងប្រគល់សាច់ប្រាក់ជូនម្ចាស់ផ្ទះរៀងរាល់ល្ងាច។ |
| បញ្ជាក់បង្កាន់ដៃ ABA | ខ.8 | បញ្ជាក់តែពេលឃើញប្រាក់ចូលគណនីពិត មិនមែនមើលតែរូប។ |
| អ្នកជួលថ្មី / ចាកចេញ | ខ.4 ខ.12 | នៅថ្ងៃចាកចេញ កត់លេខកុងទ័រចុងក្រោយ។ ម្ចាស់ផ្ទះទូទាត់ប្រាក់កក់។ |

## គ.3 សំណើជួសជុល និងអ្នកមើល

**បុគ្គលិក**៖ មើលកណ្ដឹង 🔔 រៀងរាល់ព្រឹក។ សំណើ **បន្ទាន់** ត្រូវទាក់ទងអ្នកជួលក្នុងថ្ងៃដដែល។ កំណត់តម្លៃ ចាប់ផ្តើម ហើយសម្គាល់ថារួច តាម ខ.10។ កុំចាប់ផ្តើមជួសជុលដែលអ្នកជួលត្រូវបង់ មុនគាត់យល់ព្រម។

**អ្នកមើល** (ឧ. គណនេយ្យ ឬសមាជិកគ្រួសារ)៖ មើលម៉ឺនុយដូចបុគ្គលិក តែគ្មានប៊ូតុងកែ។ ឯកសារអ្នកជួលបើកតាមតំណមានកំណត់ពេល ១២០ នាទី។ កុំថត ឬចែករំលែកទិន្នន័យអ្នកជួលចេញពីប្រព័ន្ធ។

![រូប គ.3 អ្នកមើលឃើញវិក្កយបត្រ តែគ្មានប៊ូតុងបង្កើត ឬកែ](/help/c03_viewer_invoices.jpg)

**នៅថ្ងៃឈប់ធ្វើការ**៖ ម្ចាស់ផ្ទះលុបគណនី (ខ.14) ហើយបុគ្គលិកប្រគល់សោ និងសាច់ប្រាក់ដែលនៅសល់។
