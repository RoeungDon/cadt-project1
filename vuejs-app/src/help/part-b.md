## ខ.2 ការកំណត់ដំបូង (ធ្វើតែម្តង)

កំណត់អត្រាប្តូរប្រាក់ ថ្លៃទឹកភ្លើង និង KHQR មុនចេញវិក្កយបត្រដំបូង។ មានតែម្ចាស់ផ្ទះទេដែលកែបាន។

1. **ទឹកភ្លើង → ការកំណត់**៖
    - **អត្រាប្តូរប្រាក់** (ឧ. $1 = ៤,១០០ រៀល)។
    - ថ្លៃភ្លើង និងទឹកតាមកម្រិត (tiers)៖ វិធី **A** គិតការប្រើទាំងអស់តាមអត្រាកម្រិតដែលធ្លាក់ចូល ឬវិធី **B** គិតជាជណ្តើរ។
    - ថ្លៃអប្បបរមាក្នុងមួយខែ និងការព្រមានពេលប្រើខុសពីខែមុន (ឧ. 50%)។
    - វិធី **C**៖ អត្រាផ្ទាល់ខ្លួនសម្រាប់បន្ទប់មួយចំនួន (តាមឯកតា ឬថេរក្នុងមួយខែ)។
2. **វិក្កយបត្រ → ABA KHQR**៖ ដាក់រូប KHQR (ពីកម្មវិធី ABA → Receive money → Save, PNG/JPG មិនលើស 2 MB) និងឈ្មោះគណនី។ អ្នកជួលឃើញ QR នេះពេលជំពាក់ប្រាក់។
3. **អ្នកជួល → 📝 → ម្ចាស់ផ្ទះ និងលក្ខខណ្ឌកិច្ចសន្យា**៖ ឈ្មោះ អត្តសញ្ញាណប័ណ្ណ ទូរស័ព្ទ អាសយដ្ឋានអគារ រយៈពេលកិច្ចសន្យា និងចំនួនថ្ងៃត្រូវបង់។ ឈ្មោះ និងទូរស័ព្ទនេះ ក៏បង្ហាញក្នុងជំនួយរបស់អ្នកជួលដែរ។

![រូប ខ.2ក ការកំណត់ទឹកភ្លើង និងអត្រាប្តូរប្រាក់](/help/b02_tariffs.jpg)

![រូប ខ.2ខ ABA KHQR សម្រាប់អ្នកជួល](/help/b02_khqr.jpg)

**ប្រយ័ត្ន**៖ អត្រាថ្មីប្រើតែចំពោះលេខកុងទ័រដែលរក្សាទុកចាប់ពីពេលនេះ។ លេខដែលរក្សាទុករួច រក្សាចំនួនចាស់។ បើប្តូរអត្រា សូមជូនដំណឹងអ្នកជួលមុន ៣០ ថ្ងៃ (កិច្ចសន្យា ប្រការ ៤)។

## ខ.3 បន្ទប់ និងសម្ភារៈ

បន្ទប់នីមួយៗកំណត់ថ្លៃផ្ទះ និងអ្នកទទួលថ្លៃភ្លើង។ ចូល **បន្ទប់ → បន្ថែមបន្ទប់** ឬ ✏️ ដើម្បីកែ។

| ប្រអប់ | បំពេញអ្វី |
| --- | --- |
| លេខបន្ទប់ ជាន់ ប្រភេទ | ឧ. A101 · 0 (ជាន់ផ្ទាល់ដី) · Single |
| ថ្លៃផ្ទះ / ខែ | ជាដុល្លារ |
| ថ្លៃភ្លើងបង់ទៅ | **ម្ចាស់ផ្ទះ** (កុងទ័ររង ជាចំណូល) ឬ **EDC** (នាឡិកាផ្ទាល់ មិនមែនចំណូល) + លេខគណនី EDC |
| កុងទ័រធំភ្លើង/ទឹក | បន្ទប់នេះស្ថិតក្រោមកុងទ័រធំណា (ខ.6) |
| ស្ថានភាព | ទំនេរ · មានអ្នកជួល · ម្ចាស់ផ្ទះប្រើ (គ្មានវិក្កយបត្រ) |

![រូប ខ.3ក បញ្ជីបន្ទប់](/help/b03_rooms.jpg)

**សម្ភារៈក្នុងបន្ទប់ (🛋️)**៖ ចំនួនសោ និងបញ្ជីសម្ភារៈ (ឈ្មោះ ចំនួន ស្ថានភាព កំណត់សម្គាល់)។ ប្រើ **បន្ថែមរហ័ស** និង **ចម្លងបញ្ជីនេះទៅបន្ទប់ផ្សេង** ដើម្បីបំពេញលឿន។ បញ្ជីនេះចូលក្នុងឧបសម្ព័ន្ធ ២ នៃកិច្ចសន្យា។

## ខ.4 អ្នកជួលថ្មី ប្រាក់កក់ និងកិច្ចសន្យា

អ្នកជួលថ្មីម្នាក់ត្រូវធ្វើ ៤ ជំហាន នៅថ្ងៃចូលស្នាក់។

1. **អ្នកជួល → បន្ថែមអ្នកជួល**៖ ឈ្មោះ ភេទ ទូរស័ព្ទ/Telegram អត្តសញ្ញាណប័ណ្ណ/លិខិតឆ្លងដែន សញ្ជាតិ អាសយដ្ឋាន អ្នកទំនាក់ទំនងពេលអាសន្ន បន្ទប់ (មានតែបន្ទប់ទំនេរ) ថ្ងៃចូលស្នាក់ និង**លេខកុងទ័រចាប់ផ្តើម** (ភ្លើង kWh ទឹក m³)។ បន្ថែមអ្នករួមស្នាក់ និងរូបឯកសារ (JPG/PNG/PDF មិនលើស 5 MB)។ ឯកសារទាំងនេះរក្សាទុកជាឯកជន បើកបានតែតាមតំណមានកំណត់ពេល។
2. **🐷 ប្រាក់កក់ → 1. ប្រាក់ទទួលពេលចូលស្នាក់**៖ ប្រាក់កក់ (USD) ថ្លៃផ្ទះបង់មុន ថ្ងៃទទួល និងវិធីបង់ → **រក្សាទុក** → **បោះពុម្ពបង្កាន់ដៃ**។ ថ្លៃផ្ទះបង់មុន នឹងកាត់ពីវិក្កយបត្រដំបូងៗដោយខ្លួនឯង។
3. **📝 កិច្ចសន្យា**៖ ពិនិត្យព័ត៌មាន → **បោះពុម្ព** ២ ច្បាប់ → ចុះហត្ថលេខា និងផ្តិតមេដៃ។ បញ្ជីសម្ភារៈថ្ងៃនេះត្រូវរក្សាទុកជាមួយអ្នកជួលដោយខ្លួនឯង។ ស្កេនច្បាប់ដែលចុះហត្ថលេខា ហើយដាក់ក្នុងឯកសាររបស់អ្នកជួល។
4. **គណនីចូលប្រើ → អ្នកជួល → ចេញកាត**៖ បោះពុម្ពកាត QR ពីរភាសា ហើយប្រគល់ឱ្យអ្នកជួល ជាមួយសៀវភៅណែនាំផ្នែក ក។

## ខ.5 អានកុងទ័រប្រចាំខែ (ថ្ងៃទី ២៨)

អានកុងទ័រទឹក និងភ្លើងគ្រប់បន្ទប់ដែលមានអ្នកជួល នៅថ្ងៃទី ២៨ នៃខែនីមួយៗ។ ប្រអប់ «ថ្ងៃនេះ» នៅម៉ឺនុយបង្ហាញថានៅសល់ប៉ុន្មានថ្ងៃ និងអានរួចប៉ុន្មានបន្ទប់។

1. ចូល **ទឹកភ្លើង** ហើយជ្រើសខែ (ខែមុន / ខែក្រោយ)។
2. វាយលេខថ្មីសម្រាប់បន្ទប់នីមួយៗ។ លេខចាស់បង្ហាញស្រាប់ ហើយចំនួនប្រើ និងថ្លៃគិតភ្លាមៗ។
3. ចុច **រក្សាទុកទាំងអស់**។
4. បន្ថែមរូបកុងទ័រ (📷) បន្ទាប់ពីរក្សាទុក ដើម្បីមានភស្តុតាងពេលអ្នកជួលសួរ។
5. អានគ្រប់បន្ទប់រួច → **ចាក់សោខែ** ដើម្បីកុំឱ្យកែដោយចៃដន្យ។

| ⚡ អ្នកជួលបង់ EDC | អានកុងទ័រដើម្បីតាមដាន តែមិនគិតថ្លៃភ្លើងក្នុងវិក្កយបត្រទេ |
| លេខចាក់សោ | លេខដែលមានវិក្កយបត្ររួច កែបានតែពេលទុកចោល (void) វិក្កយបត្រនោះ |

## ខ.6 កុងទ័រធំ (EDC / ទឹករដ្ឋ)

កុងទ័រធំប្រាប់អ្នកថា ភ្លើង/ទឹកបាត់បង់ប៉ុន្មានក្នុងខែ។ ចូល **របាយការណ៍ → កុងទ័រធំ** (ម្ចាស់ផ្ទះប៉ុណ្ណោះ)។

- វាយលេខកុងទ័រធំនៅថ្ងៃដដែលនឹងបន្ទប់។
- ប្រព័ន្ធប្រៀបធៀប «កុងទ័រធំ» នឹង «សរុបបន្ទប់»។ ភាគច្រើននៃភាពខុសគ្នាគឺភ្លើងកន្លែងរួម បន្ទប់ម្ចាស់ផ្ទះប្រើ («មិនមានកុងទ័រ») ឬទឹកលេច។
- ភាពខុសគ្នាធំមិនធម្មតា → ពិនិត្យទុយោទឹក ខ្សែភ្លើង ឬលេខអានខុស។
- បើប្តូរកុងទ័រធំ វាយចំនួនប្រើរបស់កុងទ័រចាស់ផង។

![រូប ខ.6 របាយការណ៍កុងទ័រធំ](/help/b06_mainmeters.jpg)

## ខ.7 ចេញវិក្កយបត្រប្រចាំខែ

វិក្កយបត្រខែ P = ទឹកភ្លើងខែ P + ថ្លៃផ្ទះខែ P+1 + ថ្លៃជួសជុលដែលអ្នកជួលយល់ព្រមបង់ − ថ្លៃផ្ទះបង់មុន។

1. អានកុងទ័រគ្រប់បន្ទប់សិន (ខ.5)។
2. ចូល **វិក្កយបត្រ** → ជ្រើសខែ → **បង្កើតវិក្កយបត្រ**។ ប្រព័ន្ធបង្កើតមួយសម្រាប់អ្នកជួលម្នាក់។
3. បើកវិក្កយបត្រមួយ ដើម្បីបន្ថែមថ្លៃផ្សេងៗ បញ្ចុះតម្លៃ ប្តូរថ្ងៃផុតកំណត់ ឬ **បោះពុម្ព**។
4. វិក្កយបត្រខុស? ចុច **ទុកចោល (Void)** សរសេរមូលហេតុ កែលេខកុងទ័រ ហើយបង្កើតម្តងទៀត។ លេខវិក្កយបត្រចាស់មិនប្រើដដែលទេ។

![រូប ខ.7ក បញ្ជីវិក្កយបត្រខែតុលា](/help/b07_invoices.jpg)

![រូប ខ.7ខ លម្អិតវិក្កយបត្រ និងការបង់ប្រាក់](/help/b07_invoice_detail.jpg)

## ខ.8 ទទួលប្រាក់ និងបញ្ជាក់បង្កាន់ដៃ ABA

- **សាច់ប្រាក់ ឬផ្ទេរផ្ទាល់**៖ បើកវិក្កយបត្រ → **បង់ប្រាក់** → ចំនួន រូបិយប័ណ្ណ វិធី លេខយោង ថ្ងៃ → **រក្សាទុកការបង់**។ បង់ជាច្រើនដងបាន។
- **បង្កាន់ដៃ ABA ពីអ្នកជួល**៖ វិក្កយបត្រ → **បង្កាន់ដៃ**។ ពិនិត្យក្នុងកម្មវិធី ABA របស់អ្នកថាប្រាក់ចូលពិត → **បញ្ជាក់** ឬ **បដិសេធ**។ ប្រព័ន្ធមិនទទួលចំនួនលើសពីប្រាក់នៅជំពាក់ ឬរូប/លេខប្រតិបត្តិការដដែលពីរដងទេ។
- **កុំបញ្ជាក់ដោយមើលតែរូប** — រូបអាចកែបាន។ សូមមើលក្នុងគណនី ABA ជានិច្ច។

![រូប ខ.8 បញ្ជាក់បង្កាន់ដៃ ABA](/help/b08_proofs.jpg)

## ខ.9 ពិនិត្យ EDC

បន្ទប់ដែលមាននាឡិកា EDC ផ្ទាល់ មាន ២ ផ្លូវបង់។ ប្រាក់ EDC មិនមែនជាចំណូលរបស់អ្នកទេ ទោះផ្លូវណាក៏ដោយ។

| ផ្លូវ | នរណាបង់ EDC | អ្នកត្រូវធ្វើអ្វី |
| --- | --- | --- |
| អ្នកជួល → EDC | អ្នកជួលបង់ផ្ទាល់ | រៀងរាល់ខែ វាយ «បំណុលចាស់» ពីវិក្កយបត្រ EDC ខែក្រោយ។ ១០០ រៀល ឬតិចជាង = បានបង់។ មិនបានបង់ → ក្លាយជាបំណុល ហើយកាត់ពីប្រាក់កក់ពេលចាកចេញ |
| អ្នកជួល → ម្ចាស់ផ្ទះ → EDC | អ្នកបង់ជំនួស | ចុះ «អ្នកជួលបង់ខ្ញុំសម្រាប់ EDC» ក្នុងវិក្កយបត្រ ហើយបង់ EDC ឱ្យទាន់ពេល |

កណ្ដឹង 🔔 រំលឹក «វិក្កយបត្រ EDC ត្រូវពិនិត្យ» រហូតដល់អ្នកវាយបំណុលចាស់។

## ខ.10 សំណើជួសជុល និងសេចក្តីជូនដំណឹង

ចូល **សំណើជួសជុល**។ សំណើថ្មី និងកំពុងធ្វើ នៅខាងលើ។ ម្ចាស់ផ្ទះក៏អាច **បន្ថែមជួសជុល** ជំនួសអ្នកជួលបាន។

1. បើកសំណើ → កំណត់ **អាទិភាព** និងកំណត់ចំណាំ (អ្នកជួលមើលឃើញ)។
2. **កំណត់តម្លៃ**៖ សេវា (USD) + សម្ភារៈ (USD) និងរបៀបបង់៖
    - **ម្ចាស់ផ្ទះចេញ** — ការរេចរឹលធម្មតា និងគ្រឿងចាស់
    - **លើវិក្កយបត្រប្រចាំខែ** ឬ **វិក្កយបត្រជួសជុលភ្លាម** — ការខូចដោយអ្នកជួល និងរបស់តូចតាច (អំពូល…)
3. បើអ្នកជួលត្រូវបង់ រង់ចាំគាត់ **យល់ព្រម** ក្នុង RTRroom។ បើយល់ព្រមផ្ទាល់មាត់ ជ្រើស **យល់ព្រមផ្ទាល់មាត់**។
4. **ចាប់ផ្តើម** → ជួសជុល → **សម្គាល់ថារួច** ជាមួយរូបមុន/ក្រោយ និងរូបបង្កាន់ដៃទិញសម្ភារៈ។

![រូប ខ.10 សំណើជួសជុល](/help/b10_requests.jpg)

**សេចក្តីជូនដំណឹងទៅអ្នកជួល**៖ នៅទំព័រដដែល → **សេចក្តីជូនដំណឹងថ្មី** → សរសេរ → ជ្រើសថ្ងៃបង្ហាញ → **ផ្សព្វផ្សាយ**។ អ្នកជួលឃើញវានៅទំព័រដើម (ឧ. «បង្កើនការប្រុងប្រយ័ត្នចេញចូល»)។

## ខ.11 ចំណាយ (ម្ចាស់ផ្ទះប៉ុណ្ណោះ)

កត់ចំណាយគ្រប់យ៉ាង ដើម្បីឱ្យរបាយការណ៍ចំណេញ/ខាតត្រឹមត្រូវ។

- **ចំណាយ → បន្ថែមចំណាយ**៖ ថ្ងៃ ចំនួន បន្ទប់ ឬ **រួម** (PPWSA កុងទ័រធំ EDC អ៊ីនធឺណេត សំរាម) និងរូបបង្កាន់ដៃ។
- **ចំណាយប្រចាំខែ**៖ អ៊ីនធឺណេត សំរាម… ប្រព័ន្ធបង្កើតម្តងក្នុងមួយខែ។ ចុច **សម្គាល់ថាបានបង់** ពេលបង់រួច ឬ **បញ្ឈប់** ពេលលែងប្រើ។
- លេខលើម៉ឺនុយ **ចំណាយ** = ចំណាយមិនទាន់បង់។

![រូប ខ.11 ចំណាយ](/help/b11_expenses.jpg)

## ខ.12 ចាកចេញ និងទូទាត់ប្រាក់កក់

ធ្វើតាមលំដាប់នេះ ដើម្បីឱ្យវិក្កយបត្រចុងក្រោយ និងប្រាក់កក់ត្រឹមត្រូវ។

1. **ពិនិត្យបន្ទប់ជាមួយអ្នកជួល** ដោយប្រើឧបសម្ព័ន្ធ ២ នៃកិច្ចសន្យា ហើយថតរូបការខូចខាត។
2. **អ្នកជួល → ប៊ូតុងចាកចេញ (ពណ៌លឿង)**៖ ថ្ងៃចាកចេញ និង**លេខកុងទ័រចុងក្រោយ** (ណែនាំ)។ បន្ទប់នឹងទំនេរ ហើយអ្នកជួលថ្មីចាប់ផ្តើមពីលេខនេះ។
3. ចេញវិក្កយបត្រចុងក្រោយ (ខ.7)។
4. **🐷 → 3. ទូទាត់ពេលចាកចេញ** (ម្ចាស់ផ្ទះប៉ុណ្ណោះ)៖

| បូកបន្ថែមលើប្រាក់កក់ | កាត់ចេញ |
| --- | --- |
| ថ្លៃផ្ទះថ្ងៃមិនបានស្នាក់ (បើជូនដំណឹងគ្រប់ ៣០ ថ្ងៃ) | វិក្កយបត្រមិនទាន់បង់ (រួមទាំងបំណុល EDC) |
| ប្រាក់បង់មុនមិនទាន់ប្រើ | ការខូចខាត និងកាត់ផ្សេងៗ |
| | ស្នាក់លើសថ្ងៃ (អតិបរមា ១៥ ថ្ងៃ) |

5. **រក្សាទុកការទូទាត់** → **បោះពុម្ពតារាងទូទាត់** → ចុះហត្ថលេខាទាំងពីរ → ប្រគល់ប្រាក់ដែលនៅសល់ និងទទួលសោវិញ។

ទូទាត់ខុស? **បោះបង់ការទូទាត់**៖ ការកាត់ត្រូវលុប ហើយវិក្កយបត្រដែលបង់ពីប្រាក់កក់ ត្រលប់ជាមិនទាន់បង់វិញ។

## ខ.13 របាយការណ៍

- **ផ្ទាំងសង្ខេប**៖ មើលរួមរៀងរាល់ថ្ងៃ (ចំណូល ប្រាក់នៅជំពាក់ បន្ទប់ទំនេរ ការងារត្រូវធ្វើ)។
- **របាយការណ៍ → ចំណេញ / ខាត**៖ ចំណូលពិត (ថ្លៃផ្ទះ ទឹក ភ្លើងកុងទ័ររង) − ចំណាយ = ចំណេញ។ ប្រាក់ EDC មិនរាប់ជាចំណូលទេ។ របាយការណ៍បង្ហាញ «ថ្លៃផ្ទះបាត់» ពីបន្ទប់ទំនេរផង។
- **របាយការណ៍ → កុងទ័រធំ**៖ មើល ខ.6។

![រូប ខ.13 របាយការណ៍ចំណេញ / ខាត](/help/b13_profit.jpg)

មើលរបាយការណ៍ចំណេញ/ខាត នៅដើមខែនីមួយៗ ក្រោយបង់ចំណាយខែមុនរួច។

## ខ.14 គណនីចូលប្រើ កាត QR និងសុវត្ថិភាព

ចូល **គណនីចូលប្រើ** (ម្ចាស់ផ្ទះប៉ុណ្ណោះ)។

| តួនាទី | ធ្វើបាន |
| --- | --- |
| ម្ចាស់ផ្ទះ | គ្រប់យ៉ាង៖ គណនី មោឃភាពវិក្កយបត្រ ប្រាក់កក់ ចំណាយ របាយការណ៍ ការកំណត់ |
| បុគ្គលិក | អានកុងទ័រ អ្នកជួល វិក្កយបត្រ ទទួលប្រាក់ ជួសជុល |
| អ្នកមើល | មើលគ្រប់យ៉ាង តែកែមិនបាន |

![រូប ខ.14ក គណនីចូលប្រើ](/help/b14_users.jpg)

- **បន្ថែមគណនី**៖ ឈ្មោះ ទូរស័ព្ទ តួនាទី និងពាក្យសម្ងាត់ (យ៉ាងតិច ៨ តួ មានអក្សរ និងលេខ)។ 🔑 កំណត់ពាក្យសម្ងាត់ឡើងវិញ។ លុបគណនី = ចាកចេញពីគ្រប់ឧបករណ៍ភ្លាមៗ។
- **អ្នកជួល → ចេញកាត**៖ កាតថ្មីធ្វើឱ្យកាតចាស់លែងប្រើ។ ស្ថានភាព **ចាក់សោ៖ លេខទូរស័ព្ទខុស** = ចេញកាតថ្មី។
- **ការចូលពីរជំហាន (2FA)**៖ ឈ្មោះរបស់អ្នក (ជ្រុងខាងលើ) → **សុវត្ថិភាពគណនី** → វាយពាក្យសម្ងាត់ → ស្កេន QR ដោយ Google/Microsoft Authenticator → វាយលេខកូដ ៦ ខ្ទង់ → រក្សាលេខកូដសង្គ្រោះ ១០ នៅកន្លែងសុវត្ថិភាព។ បុគ្គលិកបាត់ទូរស័ព្ទ៖ គណនីចូលប្រើ → 🛡 ពណ៌លឿង ដើម្បីបិទ 2FA របស់គាត់ (ក្រោយផ្ទៀងផ្ទាត់ខ្លួន)។
- **ប្តូរពាក្យសម្ងាត់**៖ សុវត្ថិភាពគណនី → ប្តូរពាក្យសម្ងាត់។

![រូប ខ.14ខ សុវត្ថិភាពគណនី និង 2FA](/help/b14_security.jpg)

**ច្បាប់សុវត្ថិភាព**៖ ម្នាក់មួយគណនី កុំប្រើគណនីរួម។ បុគ្គលិកឈប់ធ្វើការ = លុបគណនីថ្ងៃដដែល។ កុំផ្ញើរូបអត្តសញ្ញាណប័ណ្ណអ្នកជួលចេញពីប្រព័ន្ធ។

## ខ.15 បញ្ជីការងារប្រចាំខែ និង backup

បោះពុម្ពទំព័រនេះ ហើយធីករៀងរាល់ខែ។

| ពេល | ការងារ | ផ្នែក |
| --- | --- | --- |
| រៀងរាល់ថ្ងៃ | មើលកណ្ដឹង 🔔៖ បញ្ជាក់បង្កាន់ដៃ ABA និងឆ្លើយសំណើជួសជុល | ខ.8 ខ.10 |
| ថ្ងៃ ២៨ | អានកុងទ័រគ្រប់បន្ទប់ + រូបថត ហើយអានកុងទ័រធំ | ខ.5 ខ.6 |
| ថ្ងៃ ២៨–៣០ | ពិនិត្យការព្រមាន → ចាក់សោខែ → បង្កើតវិក្កយបត្រ | ខ.5 ខ.7 |
| ថ្ងៃ ១–៥ | ទទួលប្រាក់ បញ្ជាក់បង្កាន់ដៃ ពិនិត្យ EDC (បំណុលចាស់) | ខ.8 ខ.9 |
| ក្រោយថ្ងៃផុតកំណត់ | ទាក់ទងអ្នកជួលដែលហួសកំណត់ | ខ.8 |
| ដើមខែ | បង់ចំណាយ PPWSA EDC អ៊ីនធឺណេត → មើលចំណេញ/ខាតខែមុន | ខ.11 ខ.13 |
| ពេលមានអ្នកជួលចូល/ចេញ | អ្នកជួល ប្រាក់កក់ កិច្ចសន្យា កាត QR · ចាកចេញ ទូទាត់ | ខ.4 ខ.12 |

**Backup**

- Mac ធ្វើ backup database ដោយខ្លួនឯងរៀងរាល់ថ្ងៃម៉ោង **២១:០០** ទៅថត `~/RTRroom-backups`។ Mac ត្រូវបើក (មិនបិទ ឬដេក) នៅម៉ោងនោះ។
- ពិនិត្យរៀងរាល់សប្តាហ៍៖ `tail -5 ~/RTRroom-backups/backup.log` ត្រូវមាន «OK»។
- រៀងរាល់ខែ៖ ចម្លងថត backup និងឯកសារ `laravel-app/.env` (មាន APP_KEY) ទៅ hard disk ដែលអ៊ិនគ្រីប ហើយសាកស្តារម្តង។
- កុំរក្សា backup នៅ iCloud ឬ Google Drive ដែលមិនអ៊ិនគ្រីប ព្រោះមានទិន្នន័យអ្នកជួល។
